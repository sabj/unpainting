# src/paint/techniques

Named painting techniques.

- `passage-plan.mjs`: passage moves (`wet on wet`, `wet on dry`, `dry brush` and their aliases) and wet-bed preparation.
- `shaped-marks.mjs`: flat-brush marks for broad surfaces, short texture marks and parallel sky sweeps.
- `soften-lift.mjs`: a clean damp brush run along a wash's edge while it is wet.

```sh
node --test src/paint/techniques/*.test.mjs
```

[techniques.md](../../../docs/techniques.md) lists each module.
