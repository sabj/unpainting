# Technique guides for V2 and V3

These guides explain painting techniques for benchmark versions V2 and V3.

The runner copies these guides to `.agents/skills/` in each V2 worktree. `.claude/skills` links to `../.agents/skills` so both agents' command-line tools find the same files. These benchmark copies are kept separate from the current repo skills in [.agents/skills/](../../../../.agents/skills/).

## painting-planner

- [painting-planner/SKILL.md](painting-planner/SKILL.md): how to plan a whole painting. It covers style, regions, technique per region, layer order, glazes, ink, areas for close-up detail and checks.

## watercolor-technique

- [watercolor-technique/SKILL.md](watercolor-technique/SKILL.md): the light-to-dark layering model and when to break it, technique choices per subject (eyes, fur, foliage, grass, folds, architecture, sky and water), ink and graphite, and a plan check.
- [references/architecture-books.md](watercolor-technique/references/architecture-books.md): architecture, connected washes and elementary studies, from books and demonstrations.
- [references/brush-water-continuum.md](watercolor-technique/references/brush-water-continuum.md): dry brush still carries a flowing paint load, from one demonstration.
- [references/dry-detail-and-fast-studies.md](watercolor-technique/references/dry-detail-and-fast-studies.md): choosing the edge before the gesture, and small fast studies for detail.
- [references/fur-and-value-passages.md](watercolor-technique/references/fur-and-value-passages.md): fur and value passages (washes or groups of marks in one light-to-dark range) seen in four public demonstrations.
- [references/fur-value-masking.md](watercolor-technique/references/fur-value-masking.md): fur, facial form and selective masking, a process study of four videos.
- [references/SOURCES.md](watercolor-technique/references/SOURCES.md): papers, reference implementations, tutorials and books behind the skill.
- [references/trees-skies.md](watercolor-technique/references/trees-skies.md): trees and skies, a partial sequence study of four demonstrations.
- [references/whole-painting-and-calibrated-contact.md](watercolor-technique/references/whole-painting-and-calibrated-contact.md): what to check in whole paintings and tested brush contact.
