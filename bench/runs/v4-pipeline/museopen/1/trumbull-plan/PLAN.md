# Trumbull — precise architectural watercolor

## Reference cues
Warm golden limestone college building (Trumbull College, Yale) in bright sun. Central gable with circular medallion, slate roofs, tall chimneys. Cool shadows on left-facing return wall, deep blue window recesses, small figures and banners at street level. Pale blue sky with soft clouds. Foreground tree with fresh green foliage.

## Regions & technique
- Y1.sun-main-gable: sunlit warm ochre limestone — wet on dry, precise value planes, stone-block texture.
- Y1.cool-main-return: cooler left-facing wall in shadow — wet on dry, distinct value separation from gable.
- Y1.main-chimney: narrow chimney face — wet on dry.
- Y1.slate-roofs: cool grey-blue slate — wet on dry, connected cool mass.
- Y1.sky: pale blue with cloud corridors — wet on dry.
- Y1.opening-sidewalk: dark window openings, banners, sidewalk — wet on dry, recess layers.
- Y1.whole-physical-fringe: framing fringe for physical brush overhang.

## Order & moisture
Base recipe order: light-to-dark, 4 mid layers, 2 recess layers. Sky split, cold-press paper. Ink4 drawing (opening + closing) for architectural edges. Drying between value bands.

## Protected lights
Sunlit trim, window mullions, cloud lights, sidewalk — kept via value plan and paper reserve.

## Edges & values
Crisp stone edges, soft sky transitions, dark recess accents for windows. Violet shadow glaze on cool planes.

## Failure modes
Muddy stone, lost window darks, sky banding, missing chimney/roof separation, weak gable value contrast.
