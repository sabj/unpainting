# V4 and V5 inputs

In V4 and V5 the model does not paint stroke by stroke. It writes a plan for the painter (`tools/paint-plate.mjs`): regions, reserves, styles, drawing paths, recipe tokens and painter settings. Then it paints the plan with `bench/paint.sh`. The painter stops at every passage boundary, so the model can look at its sheet and revise what is not painted yet. [scripts/pipeline/round45.mjs](../scripts/pipeline/round45.mjs) runs a round.

- [TASK.md](TASK.md): the brief. [round-V4.md](round-V4.md), [round-V5-first.md](round-V5-first.md) and [round-V5-next.md](round-V5-next.md) fill its round rules; [feedback-section.md](feedback-section.md) is added from V5 try 2.
- [TOKENS.md](TOKENS.md): the recipe tokens and the painter settings each sets, generated by [scripts/pipeline/tokens.mjs](../scripts/pipeline/tokens.mjs).
- [PAINT.md](PAINT.md), [paint.sh](paint.sh) and [paint.mjs](paint.mjs): the model's paint commands. Each is a request file the harness answers.
- [check.sh](check.sh): the admission check, which runs [scripts/pipeline/check.mjs](../scripts/pipeline/check.mjs).
- [subjects.json](subjects.json): the painting width and sheet size of each target.
- [tools/](tools/): the two line tracers the brief offers.
- [example/](example/): a worked, admitted plan for a synthetic seascape that is not a benchmark target.

Rules:

- One target per session, one session per try. The model has 85 minutes of its own time. Time it waits in `bench/paint.sh` is not counted.
- Looks are unlimited (gentle self-view). The target guard stays on in the painter.
- A finished painting counts. A setting the plan asks for that the painter never reads, an option nobody asked for and a passage with no brush path are recorded in the try's `pipeline.notes` and `optionCheck`, not failed. `npm run bench:run -- ... --strict-verdict` fails the painting on them instead, as the published 0.1 results did; use it when comparing with those. A painter killed by a signal, any other painter exit than 0 or 3, and no finished painting still fail.
- If the session ends without a painting, the harness checks the plan and paints it without stops. A missing or refused plan gets one repair turn in the same session. So does a plan the painter refuses at full size.
- The pigments cannot change once painting has started.
- V5 tries after the first get `bench/feedback/`: the previous try's painting, plan, stops and judges. The model is asked to write `bench/SELF-REVIEW.md` before it reads the judges. The order is asked for, not enforced.
