Implementation notes:

- Full-sheet dry gates explicitly read paper planes and omit `waterP95`; they
  still report measured water/saturation maxima, moist share, bounds and dryness.
- JSONL strings are captured immediately, bounded by a 1 MiB flush threshold
  (plus the largest single record), and flushed at checks, pass/checkpoint
  boundaries, final consumers, throws and exits. Geometry remains in the audit
  log. Shared command IDs let composition discard geometry during streaming
  ingestion. Small CPU/GPU and native valueplan stroke statistics match O1.
- Own-contact and pigment-contact epochs retain their separate clear lifetimes.
  Aware state keeps the historical Set wire representation. Batched paper reads
  stay within one instant; full statistics remain on records that publish P95.
  Small CPU/GPU and native valueplan command logs are byte-identical between
  O2 and O3, and the native valueplan log is unchanged by O4 as well.
- Thickness reductions retain Float32 rounding and raster accumulation order.
  CPU fast drying consumes completed-step reductions; watched drying retains
  the original scan path. Parallel steps reduce their active rectangles.
- Pen gates skip measurement only with an exact-zero paper certificate.
  Instrument/flow writes and GPU version changes invalidate it; checkpoints do
  not serialize certificates, and in-place aware restore explicitly invalidates
  any existing certificate. Queued GPU drys conservatively require a read.

These are parity results, not a speedup claim or the separate 13-development-
target release sweep. No physics thresholds, painting order or seeds changed.
