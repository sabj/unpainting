## Changes

- Separate exact-zero water and dry-fixed certificates; redundant unwatched dry calls retain their tape event while skipping GPU/CPU solver and fix work. Watched dry calls still execute. Material writes, GPU version changes, and layer edits invalidate certificates.
- Certified paper observations avoid GPU readback and water/saturation scans; footprint observations still compute requested bounds and preserve existing gate/percentile result shapes.
- Early line extraction caches its record, appended flags, and generated artifacts. Output paths are normalized for cache keys and restored into the current output directory. Python package identity, target bytes, options, source code, and supplied file inputs participate in the key. Output paths embedded in generated drawing JSON are normalized for downstream plan fingerprints; caller-owned inputs retain exact byte hashes.
- A wet session retains contact ownership across shapes; physical drying clears ownership. Fast value plans default to wash session 1, preserving explicit overrides. Full-mode default remains 0.

Certificate shortcuts and cached results are intended as exact optimizations. Sharing wet sessions changes the placement of physical dry boundaries and can change rendered pixels and layering. Whole Stage 7 output is not claimed to match Stage 6 byte for byte, and this engineering benchmark does not establish a painting-quality improvement. Remaining contact-gate dry calls are reported rather than assumed eliminated.

## Method

Five serial GPU/Dawn/Metal runs on the existing Apple M4 host, using frozen `src/media/parity/workloads.json` arguments except `--runcache 1 --speedvaluecache 1 --speedprofile 1 --speedcpu 1`, with seed 0 and the required Python/checkpoint environment. Each workload has its own initially empty step cache; warm arms use a fresh process and output directory. General-540 has one cold arm. Profiling and census are enabled for every new arm so dry counts and phase observations belong to the reported render. The existing content-keyed SAM segment cache is copied into each archive, as it was already available to the baseline; step caches start empty. The specified segmentation Python has no Torch, so regenerating those segments would fail. An initial benchmark setup attempt without this cache failed before painting and is retained under `runs-setup-failed`; it is excluded from timing tables. The host was not reserved exclusively. The frozen value-plan arguments retain `--skylanes --skylanemm --skylanestep`; their declared unused-option exit 3 is accepted, and unused flags are checked against the workload manifest.

Before wall times and RSS are existing Stage 6 unprofiled observations, not newly interleaved controls. Before phases and dry counts are the corresponding corrected Stage 6 profile observations. Cold caching includes entry construction and serialization. One observation per arm; phase times are rounded and nested costs are not additive. RSS is the maximum process resident set from `/usr/bin/time -l`, excluding GPU memory and aggregate subprocess memory.

Value-plan per-shape base-dry requests fell from 2,474 to 74 (one per pass). Its main layer count fell from 2,465 to 99. Fewer layers did not reduce every storage measure: allocated main-sheet planes rose from 584.89 to 1,087.04 MiB, while peak process RSS fell from 9.808 GiB to 8.537 GiB cold / 8.685 GiB warm. Logical layer size and allocated storage are different measures; no memory reduction is inferred from layer count alone.

The paper cell counter records requested measurement cells; certified requests avoid the water/saturation loop even when the requested footprint count is nonzero. Full-sheet certified dry observations return before the per-measurement counter.
