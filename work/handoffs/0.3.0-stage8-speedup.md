# Stage 8 speedup verification

Branch: `wip/0.3.0`. Starting commit: `aad24d3fe04532c565664b50e2442bb2c440b681`.

## Summary of exact systems optimizations

1. **Async GPU dry certification & non-flushing metadata (`src/media/gpu/link.mjs`, `src/media/sheet.mjs`, `src/media/paper-certificate.mjs`, `src/media/layer-storage.mjs`):**
   - `dryQueued` sets `this.lastDryZero = true` (since `allowWet: false` is enforced), allowing `sheet.mjs` `dry()` to certify exact zero-water / dry-fixed paper state without draining the async GPU dry queue.
   - Added `sheet._rawLayers` so `certifyDryFixed`, `validDryFixedCertificate`, and `layerStorageStats` inspect layer array references without invoking the `sheet.layers` getter (which drains queued drys).
2. **Lazy exact paper observation & brush settlement (`tools/paint-plate.mjs`, `src/paint/methods/wetdry.mjs`, `src/media/brush.mjs`):**
   - `measureBrush(brush, { settle })` settles pending GPU brush state only when needed (`settle: false` in fast mode when hairs are already current).
   - Replaced unconditional per-stroke `measurePaperBatch` calls in `stroke()` with lazy exact evaluation: skipping unused `[primary, neighborPaper]` and `brushAfter` diagnostic readbacks in fast mode, using `stats: "gate"` to avoid per-stroke `waters.sort()`, and evaluating `observationCells` only when `(!own || VALUE_ACTIVE.texture)` is not already short-circuited by `gateCells`.
3. **Bounded / RLE spatial operations & buffer reuse (`tools/paint-plate.mjs`, `src/media/wash.mjs`, `src/media/sheet.mjs`, `tools/stroke-composition.mjs`):**
   - Accelerated `planDensityOfLayers` with RLE intervals and bounding boxes.
   - Reused `SHAPE_LOAD_BUFFER` with explicit `invalidateFlowField(shapeLoad)` in `src/media/wash.mjs`.
   - Added bounded `maskWindow`, `openEdgeShare`, memoized `sweepCover`, `stableClipMask` run caching, and tight bounded erosion in `tools/stroke-composition.mjs`.
