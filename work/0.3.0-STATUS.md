### Implementation and validation

- Unified provenance schema in `run-cache.mjs`, consumed by state I/O and run cards. Cache hits replay target-look accounting. Checkpoints store `provenance.json` and reject changed fields before loading arrays. Plan content hashes are captured during setup; checkpoint hashes use the finalized linked drawing stages.
- Persistent stat-manifest content hashes include source identity and the dependency lock; scoped closure hashes isolate palette, paper, separator and pen-field dependencies. The callback implementation participates in the step fingerprint. Conservative whole-source hashes remain for larger closure-heavy steps.
- Cached main/fine paper, CAL plus GRADED_CAL (with tracked option reads and explicit pigment/physics/paper/material inputs), SEP and the deterministic pen ridge field. Calibration caching is disabled for semantic area/finish plans whose command evidence must execute.
- INKRES restores fine-sheet material, carry-down buffers and wet state; derived optical caches rebuild. PREPF is saved/restored. Physical array type/length disagreement is refused.
- `score_painting.py --resolution native --target HIGH_RES --image PAINTING --plate-mm 200` keeps rendered resolution, requires a sufficiently large target, and records the scoring geometry. Legacy remains the default. Classic filters use physical widths; deterministic metrics cache by aligned image pixels, geometry, physical width and implementation hashes. No paid vision rescore or ranking claim was made.
- `run-pair.py` now accepts frozen per-workload argv and records archive SHA-256 and per-run peak RSS. Offline benchmark fixtures explicitly declare their intentionally dirty sanitized worktree; ordinary contestant runs retain the refusal.
